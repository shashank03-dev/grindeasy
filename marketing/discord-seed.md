# Discord seeding — Monday

This is your highest-leverage channel and it is not close. grindeasy's growth loop
lives *inside* Discord: every user who installs it becomes a live billboard on their
own profile, in every server they're in, while they work. One person in a busy dev
server is worth more than a hundred impressions on Twitter.

## Rules for not getting banned

You're posting in servers you're a member of, not servers you own. Treat that as a
budget you can spend once.

- Post in `#showcase`, `#projects`, `#self-promo`, `#i-made-this` — whatever the
  server designates. If there is no such channel, **do not post.** Skip that server.
- One message. No follow-up bump. No DMing members.
- If you've never spoken in that server, you have no standing to post in it. Answer
  two questions in `#help` first, on another day.
- Be present in the thread for the next hour. This is the whole point — the people
  who reply are your first 50 board members.

## The message

Short, because long self-promo posts in Discord get scrolled. The card screenshot
does the work.

> Been building this for a couple months — it's a tiny local agent that puts what
> you're actually coding with on your Discord profile, live.
>
> It watches Claude Code, Codex, Cursor, OpenCode, Gemini CLI and Aider (+ Zed,
> Continue, Copilot Chat, Cline if you have them) and shows a Rich Presence card
> while you're in a session. There's a leaderboard for active hours if you want it —
> opt-in, off by default.
>
> The part I actually care about: it never reads your code. It decides a tool is
> "active" purely from the modification time of that tool's session files. It never
> opens them. Nothing leaves your machine unless you explicitly join the board.
>
> `npx grindeasy` — free, MIT, Node 20+, needs the Discord desktop app for the card
> to show. Source: https://github.com/shashank03-dev/grindeasy
>
> [attach the card screenshot]

## Attach this

The card itself, on a real profile, mid-session. Not a mockup, not the terminal.
The card is the product — the screenshot has to be of the thing that goes on *their*
profile, so they can picture it on theirs.

## The follow-up that actually converts

When someone replies "oh that's cool" — that's your opening, and it's the highest
converting sentence you will write all week:

> if you install it now you'll be like top 20 on the board lol, there's barely
> anyone on it yet

Early-rank scarcity is real and it expires. Use it this week, because in a month
"you'll be #400" is not a pitch. This is the entire reason the seeding phase runs
before HN.

## Where to post

You know your servers better than I do, but rank them by: (a) do people there use
Claude Code / Cursor / Codex daily, (b) is there a showcase channel, (c) have you
ever spoken there. Hit the top 4–6. Don't carpet-bomb 20 servers in one night —
that's how you get flagged, and the loop only needs a handful of seeds to start.
